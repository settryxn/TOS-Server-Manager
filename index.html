Termes de Service du Serveur Discord "Server Manager"

Introduction

Bienvenue sur le serveur Discord "Server Manager". En rejoignant ce serveur, vous acceptez de respecter les termes de service suivants. Ces termes visent à maintenir un environnement respectueux, sûr et productif pour tous les membres.

Règles Générales d'Utilisation

  • Respectez tous les membres : Aucun harcèlement, insultes ou comportements agressifs ne sont tolérés.
  • Contenu approprié : Évitez tout contenu offensant, violent, sexuel ou illégal.
  • Spam : Ne spammez pas les canaux avec des messages répétitifs ou inutiles.
  • Langue : La langue principale est le français, mais l'anglais est accepté dans certains canaux.

Modération

Les modérateurs ont le droit de sanctionner les violations des règles. Les sanctions peuvent inclure des avertissements, des kicks, des bans temporaires ou permanents. Les décisions des modérateurs sont finales.

Confidentialité

Nous respectons votre vie privée. Les informations personnelles ne sont pas collectées sans consentement. Cependant, les messages publics peuvent être visibles par tous les membres.

Responsabilités

Vous êtes responsable de vos actions sur le serveur. En cas de problème, contactez un modérateur via les canaux appropriés.

Modifications des Termes

Ces termes peuvent être modifiés à tout moment. Les membres seront informés des changements majeurs.

Contact

Pour toute question, contactez l'équipe de modération via le canal #support.
